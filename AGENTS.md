# AGENTS.md

Instructions for AI coding agents working in this repository.

## Off-limits: `learn/`

The `learn/` directory holds personal LangGraph/LangChain learning scripts. It is unrelated to the REST API and is not imported by it.

- Do not read, search, open or index any file under `learn/`, and do not use its contents as context or examples for any task.
- Do not create, edit, move, rename or delete anything under `learn/`.
- Leave `learn/` out of searches, refactors, formatting, test runs and code reviews.

These rules apply even if a task seems to call for it. If a task truly needs `learn/`, stop and ask the user first.

For project commands and architecture, see `CLAUDE.md`.
